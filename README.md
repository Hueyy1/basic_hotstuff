## Project Structure
```
├── Makefile  # used for build docker image and start demo
├── README.md
├── configs
│   ├── config-map-docker.yaml  # config file for starting demo in docker
│   ├── config-map.yaml  # config file for start service locally
│   ├── replica0_private.pem  # cert file
│   ├── replica0_public.pem
│   ├── ...
├── deploys
│   ├── compose  # dockerfile
│   └── docker  # image build file
├── docker-entrypoint.sh
├── files.zip  # raw metric data for backup, also used to generate figures used in report
├── files
│   ├── metric_with_total_10_fault_0_with_cogsworth.csv  # metric data
│   ├── ...
├── go.mod
├── go.sum
├── logs
│   ├── main_0.log  # log file for executing "python3 run_experiments.py"
│   ├── ...
├── src
│   ├── cmd  # command line
│   ├── consensus  # consensus protocol implementation
│   ├── crypto  # ECDSA implementation
│   ├── log  # log config
│   ├── main.go  # entrance
│   ├── model  # data model
│   ├── proto  # proto files
│   ├── server  # grpc server implementation
│   ├── service  # common services for consensus
│   ├── testutil
│   └── types  # data types for consensus
└── visualization
    ├── figure.zip  # figures generated by generate_figures.py, which are used in report. it's backup.
    ├── generate_figures.py  # generate figures
    ├── requirements.txt  # python venv requirements
    └── run_experiments.py  # use script to run demo with different params to simulate different scenarios.
```


## System Requirement
```shell
go 1.24.4
python 3.11
macos/linux
```


## Getting Started Locally
```shell

# workdir ./hxy352/src
go build -o main

# generate certs if there is no certs in configs
#./main generate-certs

# start nodes
./main bhs --id=0 --fault_number=0 --total_number=4 --pacemaker_loaded=false
./main bhs --id=1 --fault_number=0 --total_number=4 --pacemaker_loaded=false
./main bhs --id=2 --fault_number=0 --total_number=4 --pacemaker_loaded=false
./main bhs --id=3 --fault_number=0 --total_number=4 --pacemaker_loaded=false

# start client
bhs-client --fault_number=0 --total_number=4 --pacemaker_loaded=false
```

## Getting Started Using Docker
```shell
# workdir ./hxy352

# pull image from dockerhub
make pull

# start demo
make run

# stop demo
make stop
```

## Visualization
```shell
# create virtual environment, python >= 3.11
cd visualization
python3 -m venv venv
pip install -r requirements.txt

# run nodes and client, to get raw metrics data
python3 run_experiments.py

# generate figures
python3 generate_figures.py
```

## Gorums Proto

# the lastest version has problem with protoc cmd

  --go_out=paths=source_relative:. \
